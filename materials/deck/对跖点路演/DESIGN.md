# DESIGN · 对跖点路演

> 场景未命中学术 / 咨询 / 政务三类预设分支 → 走通用设计法则（universal-only）。
> 视觉隐喻：**对跖点** —— 一个球面上正对着的两个点，永远看不到彼此。全片只用两种"面"：暖纸面（已知）与墨色面（未见），交界处用一道朱线。

## 1. 画布与母版

| 区 | 垂直位置 | 高度 | 内容规则 |
|---|---|---|---|
| A 标题块 | 0–120px | 120px | 小标签 14px（蓝）+ 主标题 36px bold；左对齐 |
| B 内容区 | 120–660px | 540px | 正文 / 卡片 / 图示 |
| C 页脚条 | 660–720px | 60px | 左：ANTIPODE · TECHATHON 2026（14px, 40% 灰）；右：`NN / 09` |

页面 padding：上下 20px、左右 60px。封面 / 收束页不受 A/B/C 约束。

## 2. 颜色（4 hex）

| 角色 | hex | 用途 | 面积 |
|---|---|---|---|
| 墨 ink | `#14161A` | 深色页背景、正文主色 | ≤ 55% |
| 纸 paper | `#F7F5F0` | 浅色页背景、深色页上的文字 | ≤ 60% |
| 蓝 blue | `#2F5BE4` | 主色：标签、强调、正向数据 | ≤ 10% |
| 朱 vermilion | `#C2410C` | 强调色：**只标记"另一面"**（反库侧、警示、局限） | ≤ 8% |

辅助中性色：`rgba(20,22,26,0.55)` 次级文字、`rgba(20,22,26,0.10)` 分隔线、`rgba(247,245,240,0.14)` 深色页分隔线。

**渐变 / 半透明策略**：仅封面与收束页用 `linear-gradient(120deg, #14161A 0%, #1D2430 100%)`；朱色永不铺面，只做线、点、小标签。

**页面色彩映射**：01 墨、02 纸、03 纸、04 墨、05 纸、06 纸、07 纸、08 墨、09 墨 —— 深浅交替，保证任意相邻两页色彩比例差异 > 20%。

## 3. 字体

| 层级 | 字体 | 字号 | 字重 | 行高 |
|---|---|---|---|---|
| 封面主标题 | 微软雅黑 | 88 | bold | 1.15 |
| 收束大字 | 微软雅黑 | 64 | bold | 1.2 |
| 巨型数字 | Arial | 96–120 | bold | 1.0 |
| 页面主标题 | 微软雅黑 | 36 | bold | 1.3 |
| 卡片标题 | 微软雅黑 | 26 | bold | 1.35 |
| 正文 | 微软雅黑 | 21 | regular | 1.55 |
| 小字 / 标签 | 微软雅黑 | 14 | regular | 1.4 |

西文与数字统一 Arial（与中文形成字重对比）。全片 ≤ 2 套字体家族。

## 4. 密度与留白

- 内容页留白 ≤ 35%；封面 / 收束页 ≤ 55%。
- 每页至少 1 个视觉锚点：巨型数字（≥ 72px）或大色块 / 大圆。
- 卡片内文字垂直填充 ≥ 85%，尾部元素用 `marginTop: 'auto'` 钉底。
- 禁止连续两页出现"三等宽卡片横排"。

## 5. 配图

全片不使用摄影 / 插画。视觉元素分两类：

- **L1 主视觉**：原生图形（对跖点圆环、双栏界面示意、漏斗条），用 `Box` + `Text` 直接构图，随页面一起缩放，避免位图模糊。
- **L3 角标**：无（页脚只放文字）。

## 7. 自检

- [ ] 每页 L1 占 B 区 ≥ 30%（数据页 ≥ 50%）
- [ ] 相邻页版式不同、视觉重量差 > 1.5:1
- [ ] 只用 4 个 hex + 3 个中性透明度
- [ ] A/B/C 三区位置每页一致（除 01 / 09）
- [ ] 无溢出：累计高度 ≤ 720px
