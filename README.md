# Antipode · 对跖点

> TECHATHON 2026 参赛项目 · 暂定名，可随时更换

**一句话：** 它帮你把"你关注的信息"收进一个仓库，再自动为你建一个**反仓库** —— 存放那些你**没看见、但值得看见**的信息。

---

## 1. 它解决什么问题

今天的信息工具都在做同一件事：**把你想看的推给你。**

结果是每个人的信息视野越用越窄 —— 你关注微服务，它就只给你微服务；你相信 TDD，它就只给你 TDD 的成功案例。**没有人负责告诉你："这件事还有另一面。"**

Antipode 做了两件事，而且是对称的：

| 仓库（Vault） | 反仓库（Antipode） |
|---|---|
| 你说要什么，它去各个源里筛 | 它专门去找**与这些信息相对立/互补**的内容 |
| 让你**读得完** | 让你**看得见盲区** |
| 排序：契合度 × 时间 | 排序：对立度 × 论证质量 |

---

## 2. 核心概念：`相反` 不是一种东西，是三种

> 这是整个产品的设计地基。不区分的话，反仓库必然退化成"杠精池"。

| 类型 | 定义 | 例子 | MVP |
|---|---|---|---|
| **A 观点对立** | 同议题、反立场 | 你信微服务 → 推"单体更好" | ✅ 先做，用来跑通链路 |
| **B 反向证据** | 反驳你结论的具体事实 | 你信"微服务=高可用" → 推"某公司因微服务宕机 12 小时" | ⭐ 演示亮点 |
| **C 视野缺失** | 你完全没覆盖的相邻议题 | 你只看微服务 → 推 Serverless | ⭐ 架构留位，人工预置 1 个例子 |

数据模型里用 `counter_type` 字段**一次性把三个位置留出来**，否则后期改不动。

## 3. 它是怎么工作的

```
用户一句话  →  授权信息源  →  双仓库
   │
   ├─ 采集层：GitHub / 邮件(IMAP) / RSS … 全部转成同一个文档 Schema
   │
   ├─ 智能层：① 主题+立场抽取  ② 生成对立假设  ③ 检索真实来源  ④ 验证打分
   │
   └─ 仓库 ← 契合度排序       反仓库 ← 对立度 × 论证质量 排序
                                  └─ 每条都带「回现场」深链接
```

**贯穿全流程的一条铁律：**

> **LLM 只负责「提出问题」，绝不负责「提供答案」。答案必须来自真实检索。**

这是防幻觉唯一可靠的方式，也是答辩时最该强调的技术原则。

**防杠精化三道闸门（缺一不可）：**
1. 必须有**论证结构**（没有"前提 → 结论"的一律丢弃）
2. 必须有**可验证出处**（没有 URL 的一律丢弃）
3. 对立度必须达阈值

> 反仓库排序里，`对立度` 只占 40%，`论证质量` 同样占 40%。
> 用评分机制强制"不要抬杠，要讲理"。

## 5. 快速开始

```bash
git clone <repo-url>
cd <repo>

# Python 依赖
python -m pip install -r code/requirements.txt

# 配置密钥（真实密钥只写在 .env 里，绝不要提交）
cp code/.env.example code/.env

# 自检（不花钱，不调用 API）
python code/stance_extractor.py --selftest

# 真实抽取一条
python code/stance_extractor.py --text "我们去年上了微服务，排障时间翻了三倍。"

# 跑评测集
python code/stance_extractor.py --eval code/gold_set.jsonl
```

详细步骤见 [`docs/快速上手_操作手册.md`](docs/快速上手_操作手册.md)。

## 6. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 接入层 | GitHub REST API（PAT）/ IMAP | **不用 OAuth**，黑客松现场最容易翻车 |
| 数据层 | Postgres + pgvector | 文档元数据 + 向量 |
| 智能层 | DeepSeek / GLM / GPT（OpenAI 兼容接口） | 结构化输出 + LLM as Judge |
| 检索 | 向量 + BM25 混合（RRF 融合） | 单用向量会漏精确术语 |
| 编排 | 异步任务队列 | 采集 + 多次 LLM 调用 > 30s，同步请求必然超时 |
| 交互层 | Next.js | 结果卡片 + 「回现场」深链接 + 授权面板 |

## 9. 路线图

- **P0（第 1–6 小时）** 硬编码议题 → 一张仓库卡片 + 一张反卡片 → 点击跳转。**这条链路不通，后面全是空中楼阁。**
