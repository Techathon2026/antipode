## 三、评审标准（100 分）⭐

| 分值 | 维度 | 考察点 |
|---|---|---|
| **30** | 创新性 | 选题 · 方案 · 场景 |
| **30** | 技术完成度 | 功能 · 稳定 · 工程 |
| **40** | 成果呈现与答辩 | 交付材料 · 路演 · 整体表达 |

**官方原话：**

> **先让核心功能稳定运行，再把成果讲清楚。**

### 对我们的意义

- **呈现与答辩占 40%**，比创新和技术的单科都高 → 材料、PPT、5 分钟路演、问答预案必须与开发同等重视。
- **15:00–17:00 是评委巡场**，不是只看最后路演 → 现场 Demo 必须在这两小时里随时可演示、不崩。
- **17:00 代码冻结** → 之后一律不要动核心功能，只做演示保障。

### 影眸 Hyper3D

- 会员兑换码：`现场发放(真实值仅存本地, 不入库)`
- **必须用上科大邮箱注册**
- 用途：文本/图片生成 3D 模型 → 我们的 3D 信息星图

### ⚠️ DeepSeek 资源待确认事项

资源页只给了 key 和 model 名，**没有给 API 接口地址（base_url）**。

实测结论：
- 该 key 直接请求 DeepSeek 官方接口（`https://api.deepseek.com`）返回 **401 无效**。
- 说明它是**比赛方自建网关**的密钥，官方 model 名应为 `deepseek-flash`，而现场写的是 `deepseek-pro`。

**行动项：**
1. 向现场工作人员 / 赛事群确认 **base_url 与 model 名**
2. 拿到后写入 `code/.env`，用 `code/check_api_key.js` 一分钟验证
3. 若迟迟拿不到，先用自备的 DeepSeek / 智谱 GLM / OpenAI 密钥替代，**不要阻塞开发**
