# 演示视频 · 分镜脚本（3 分钟）

> 提交清单建议演示视频 ≤ 8 分钟（MP4）。我们录 **3 分钟**：评委的时间比视频长度更贵。
> 全程**不依赖网络**（演示页是静态文件），现场网络翻车也不影响录制。

---

## 一、录制前 10 分钟准备

| # | 动作 | 说明 |
|---|---|---|
| 1 | 关掉微信 / QQ / 邮件通知 | 录屏时弹窗是灾难 |
| 2 | 浏览器缩放调 **110%** | 1080p 下文字才看得清 |
| 3 | 先跑一遍 `python code/make_demo_page.py` | 确认数字与最新产物一致 |
| 4 | 打开三个标签页备用 | 演示页 / 答辩看板 / GitHub 仓库首页 |
| 5 | 录屏软件 | Windows 用 `Win + G`（Xbox Game Bar）或 OBS；输出 1920×1080、MP4 |
| 6 | 麦克风试录 10 秒 | 听回放，确认没有电流声、没有回声 |

> 不要边跑在线检索边录：单条 30–120 秒，中间长时间黑屏。检索过程用**截图 + 旁白**交代。

## 三、旁白逐字稿（约 620 字，3 分钟）

**[0:00]** 这是对跖点。它给你的信息库再建一个反仓库：左边是你收的，右边是你没看见的。

**[0:15]** 左边这三条，是用户收藏的技术文章 —— 支持微服务、支持 TDD、选了 React。

**[0:30]** 右边是系统自动找出来的：同一场争论里，站在另一边的真实文章。比如这一条，「从微服务走向单体化」，对立度 0.95。

**[0:50]** 反推荐是一个可选开关，按库开启。像邮件、代码 issue 这种私人事务，本来就没有「对立面」，我们默认不开。

**[1:05]** 每一条都能点回原文。我们点一下这条 —— 原文在这里，页面里引用的那句话，是原文里逐字截出来的，不是概括、不是改写。

**[1:30]** 找不到的时候，右栏不会留空，也不会编。它会写清楚原因：这篇是中立的、这个议题不在我们的表里、或者候选全被闸门拒掉了。

**[1:50]** 这是整库跑一次的账：184 个检索候选，粗筛后 56 个送进模型，最后留下 6 条。3.3% 的留存率不是失败 —— 留下的每一条都能点开核对。

**[2:20]** 其他 178 条去哪了，我们也记着：最多的是「站错边」，25 条 —— 检索召回的东西看着相关，其实不是反方。

**[2:40]** 仓库之外，还应该有一层。不是让你看得更多，是让你看见自己没在看的那一面。

## 四、翻车预案

| 情况 | 处理 |
|---|---|
| 演示页打不开 | 直接双击 `docs/反库演示.html`（本地文件，不需要服务器） |
| 想展示在线检索但网断了 | 播放已录好的这段视频，或切到 `data/antipode_demo-vault.jsonl` 展示产物 |
| 时间被压缩到 2 分钟 | 只保留：0:00–0:50（是什么）+ 1:05–1:25（证据）+ 2:40（收束） |
| 评委要求现场看跑一次 | 跑 `python code/run_vault.py --vault data/vault_demo.json --limit 3`，说明单条 30–120 秒 |
