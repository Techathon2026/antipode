# 校园邮件标题采集与标注

本工具在自己的电脑上，通过学校公开支持的 IMAP 服务读取本人邮箱的邮件头，导出待标注 CSV。只用 Python 标准库，无需安装第三方依赖。默认读取全部可选择文件夹的全部邮件，不抽样、不限制为 500 封。包括服务器列出的收件箱、归档、自建文件夹、已发送、草稿、垃圾邮件和已删除等文件夹（以实际权限为准）。不包含服务器已永久删除的邮件。

## 1. 生成客户端专用密码

1. 打开 https://mail.shanghaitech.edu.cn/ ，自己登录。
2. 进入「设置 → 安全设置 → 客户端专用密码 → 生成专用密码」。
3. 名称填写 `Techathon邮件采集`，生成后保存在本地。不要发送到聊天，也不要写入代码。
4. 学校说明：启用二次验证后，第三方客户端必须使用专用密码。此密码仅在生成时显示，丢失时需要重新生成。

官方说明：https://it.shanghaitech.edu.cn/2025/0619/c13047a1112015/page.htm

服务参数：`imap.shanghaitech.edu.cn`，端口 `993`，SSL/TLS；用户名为完整校园邮箱地址。

## 2. 准备 Python

在 Windows 的 PowerShell 中输入：

```powershell
python --version
```

如果显示 Python 3.10 或更新版本，可以继续。如果命令不可用或跳转 Microsoft Store，请从 https://www.python.org/downloads/windows/ 安装受支持的 Python 3，安装时启用「Add python.exe to PATH」（若安装器提供此选项），然后重新打开 PowerShell 验证。若电脑只提供 `py` 命令，后续命令中的 `python` 可替换为 `py -3`。

## 3. 先试读 10 封

在 PowerShell 中依次执行：

```powershell
Set-Location D:\documents\techathon2026\email_scraper
python collect_email_headers.py --limit 10
```

先选择保存方式：输入 `new` 新建带时间戳的 CSV；或者输入已有 CSV 的完整路径，追加新邮件。交互输入的已有路径必须确实存在，以免拼错文件名后误以为继承成功。然后输入完整邮箱地址，例如 `你的用户名@shanghaitech.edu.cn`，回车；再输入客户端专用密码，回车。密码输入时不显示星号或字符，这是正常现象。

成功时会显示邮件数量和 CSV 完整路径。先打开文件，确认标题没有乱码、`label` 列为空。

## 4. 一次读取全部邮件

```powershell
python collect_email_headers.py
```

默认交互选择保存方式，输入 `new` 才新建文件；输入已有 CSV 路径则追加。追加保留旧行、标签及自定义列，新行的标签和自定义列为空。按 Message-ID 去重（缺失时按邮件编号与标题、发件人、日期、文件夹组合匹配），旧文件已有重复行不清理。输入不同邮箱也可以合并，不会仅凭不同邮箱之间可能碰巧相同的 UID 判重。

采集过程只获取邮件头，不下载正文和附件，不调用大模型。以只读方式打开文件夹，并使用 `BODY.PEEK` 保持已读状态。内部每 100 封分批传输，但一次运行会读取全部邮件，不需要你反复运行。去重使用集合查找，避免逐封遍历旧表；仍需读取全部邮件头才能识别新记录。

保存前请关闭 Excel 中的目标文件。追加时先在同目录临时文件中复制原数据并追加新行，完成后替换原文件；失败时保留原文件。没有新邮件时不重写文件。

也可跳过保存方式提问，直接在命令中指定：

```powershell
python collect_email_headers.py --output new
python collect_email_headers.py --output "D:\documents\techathon2026\data\email_headers_20261016_180127.csv"
```

`--output` 指定已有路径时追加，指定不存在的 `.csv` 路径时新建。相对路径以当前 PowerShell 目录为准，建议继承时填写完整路径。

若你的 500 多封邮件都在收件箱，且只希望获取这些邮件：

```powershell
python collect_email_headers.py --inbox-only
```

输出按文件夹、各文件夹内较新邮件优先排列。每封邮件保留一行，不自动去重；同一邮件位于多个文件夹时会有多行，方便核对是否全部读完。`folder` 列显示来源；后续训练时可按 `message_id` 和线程信息统一去重及分组。邮箱在读取过程中收到的新邮件可能需要下一次运行才会采集；程序会提示采集过程中移走或未返回的邮件。

## 5. 人工标注

用 Excel 打开输出的 CSV：

- `subject`：标题，是当前计划用于模型训练的输入。
- `sender` / `date`：发件人和发信时间，辅助你定位原邮件。日期保留邮件头原始内容，不保证是到达邮箱的时间。
- `label`：当前任务为主题八分类，填写 `T01`～`T08`；未判断先留空。类别定义见 `../docs/email_label_taxonomy_v2_draft.md`。
- `folder`：邮件所在文件夹。标注前可按此列排除已发送、草稿等不适合收件筛选任务的数据。
- `needs_body`：必须查看正文才能判断时填 `1`；只凭标题即可判断时可填 `0`。
- `id` / `message_id` / `group_id`：保留不改，方便查重及后续按线程划分训练集和测试集。缺失邮件头的线程可能仍需人工归并。

按项目八类主题的统一标准标注，不要直接把已读或星标当作标签。建议先标 50 封，复查标准是否一致，再继续。

如果只看标题无法判断，可以到网页邮箱搜索标题并查看正文；这个工具不会提取正文。后续评估应单独检查 `needs_body=1` 的样本。

保存时继续使用 **CSV UTF-8（逗号分隔）** 格式，避免中文乱码。工具将邮件头中的换行整理为空格，并为以公式符号开头的内容添加英文单引号，防止表格执行邮件里的公式；后续训练导入时应按此规则恢复文本。

## 常见问题

- **登录或访问失败**：检查是否输入完整邮箱地址、专用密码有无复制空格、是否已开通客户端访问；不要连续反复尝试。学校技术支持为 `it-support@shanghaitech.edu.cn`。
- **连接超时**：检查网络，尝试正常可用的校园网络；公开说明没有确认所有校外网络均可访问。
- **只导出很少邮件**：检查是否使用了 `--limit` 或 `--inbox-only`；默认读取服务器允许列出的所有可选择文件夹。
- **CSV 已存在**：程序会追加未出现的邮件，保留既有标注；若不能读写，先关闭 Excel 再运行。
- **没有 Python**：先完成第 2 步，本工具不需要 CUDA，也不需要先配置深度学习环境。

邮件数据默认写入已被 Git 忽略的 `data/` 文件夹。公开项目时不要手动提交原始邮件数据。生成专用密码、真实登录及导出需由本人在本地完成；离线检查通过不代表真实账号接入已验证。
